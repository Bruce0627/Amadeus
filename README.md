# Amadeus System：加入簡易自主生活

[English](README.en.md)

在 Windows 桌面上和 Amadeus 聊天。

## 加入簡易自主生活

這次公開的原始碼包含 v1.1.1 之後的更新。自主生活預設關閉；要使用本次更新，請從儲存庫原始碼執行，現有安裝套件仍是 v1.1.1。QQ 代管、QQ 空間、語音傳送、待辦和提醒等已有能力繼續保留。

本次更新讓閱讀、閒聊、整理想法和空間分享分別安排時間，並把你與她的 QQ 私訊接入共同日常。這次也新增了閱讀公開來源、選用 QQ 語音辨識，以及依對話補讀遺漏訊息的功能，以及分段回覆、逐段模擬打字所需的時間、表情輪換和桌面貼上圖片。Bluesky、Bangumi、arXiv 和 RSS/Atom 新增的功能僅限讀取公開內容。

Amadeus System 是一個《命運石之門》同人專案。桌面上的 Live2D 角色以牧瀨紅莉栖為原型，能陪你聊天、記住你說過的事、幫你管理待辦和提醒，可以用中文或日語開口說話，口型跟著聲音動。

## 能做什麼

- **聊天和記憶**：她會記住你的偏好和長期在做的事，換個對話也還記得。
- **待辦和提醒**：在待辦面板裡新增，或者直接說「明天上午九點提醒我開會」；也可以讓她過一會兒再讀一段話給你聽。提醒和延後執行的任務需要保持程式執行。
- **提醒完成狀態**：一次性純提醒可在成功送達後自動移出未完成清單；需要你親自做完的普通待辦仍由你確認，重複任務繼續保留下次安排。
- **週期任務**：例如「每週一上午九點，根據我當前研究興趣推薦論文」。可以透過對話修改內容、暫停和恢復，也可以在待辦編輯器設定「到點動作」和週期。後端開啟時會自動執行，結果儲存後交給桌面顯示；後端停止或電腦休眠期間不會準時執行，恢復後合併補執行一次。
- **語音和表情**：桌面朗讀支援中文、日文，表情和動作跟著內容變化；QQ 的文字或語音、語言和語音比例可以另外設定。QQ 相簿支援靜態圖片和 GIF 動圖，保留原始圖片傳送。
- **看圖和查資料**：桌面聊天框可直接貼上圖片。在你允許後，她可以看圖片、螢幕截圖和攝影機畫面，讀寫文字檔案，網路搜尋並給出來源。
- **網路研究**：在瀏覽器設定中選擇 DeepSeek 搜尋、Bing 或 DuckDuckGo，並設定備用方式。查詢可繼續讀取網頁、PDF 文字、定位關鍵字和翻頁；預設 quick / standard / deep / exhaustive 的工具呼叫次數上限為 12 / 32 / 64 / 160 次，研究時間上限為 60 / 120 / 240 / 600 秒，可在設定中調整。預算並非必須用滿；網站拒絕連線、掃描 PDF 無文字等情況仍會如實報告。
- **QQ 代管**：按好友或群分別設定是否回覆、觸發方式、回覆身分、人格、語音和間隔；支援按意思分段、模擬打字所需的時間、圖片/表情包、引用和歷史訊息。主人可以透過 QQ 控制已開放的工具，帳號設定和各自上下文分開儲存。
- **接收 QQ 語音**：準備好可選的本機語音辨識環境和模型後，可以直接傳送 QQ 語音；辨識結果進入普通聊天流程，不改變傳出的語音設定。
- **登入後補回**：在具體好友或群的設定中開啟「登入後補回遺漏訊息」。預設關閉，從開啟時開始記錄；下次登入或重連補看最近最多 90 條訊息並集中回覆，保留暫停、審核和群觸發設定。
- **人格與表達**：本機預設使用紅莉栖人格；QQ 對象可選紅莉栖、孫吧或抗吧獨立人格。論壇模式只讀取本機已安裝的語料；孫吧/抗吧語料不隨公開原始碼或 Release 分發，未安裝時仍可選人格但不會載入論壇示例。
- **主動互動與等待**：可以讓她暫時安靜等待；Live2D 的月牙標記表示等待狀態，你主動發訊息仍可得到回應。
- **自主生活（簡單實驗性功能）**：按自己的興趣定時閱讀授權目錄、公開網頁、Bluesky 動態、Bangumi 條目、arXiv 摘要和 RSS/Atom，保留獨立的閱讀日記與待探索問題；以閱讀、聊天、整理想法和考慮空間分享四個獨立節律執行，可產生 QQ 空間草稿，或按你設定的帳號和發布額度自動發布。預設關閉，尚未包含在 v1.1.1 安裝套件中。
- **外觀**：桌面懸浮和視訊通話兩種版面，兩套服裝，背景可以換成自己的圖片。

## 安裝

1. [下載安裝器 AMADEUS-v1.1.1-setup.zip](https://github.com/Akatosh6DW/Amadeus/releases/download/v1.1.1/AMADEUS-v1.1.1-setup.zip)（約 17 KB；完整程式由安裝器下載）。
2. 解壓後雙擊 `install-release.cmd`，安裝器會自動下載程式、執行環境和聲音資源，預設安裝在 `%USERPROFILE%\Apps\Amadeus`。
3. 執行 `AMADEUS.exe`，在「設定 → API」裡填入你的 API Key。

預設使用 DeepSeek（Endpoint `https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`）。也支援設定其他相容 OpenAI 介面的服務；看圖功能需要模型支援圖片輸入。

v1.1.1 整合 QQ 代管與獨立人格，修復提醒、記憶、歷史紀錄與語音功能，並改善自動更新的程序間的交接。舊版使用者請先用本版安裝器升級；以後可在「設定 → 更新」檢查並安裝新版，繼續使用原有設定和聊天紀錄。詳見 [發行說明](https://github.com/Akatosh6DW/Amadeus/releases/tag/v1.1.1)。

## 從原始碼執行

要使用「加入簡易自主生活」及其他本次原始碼更新，請從當前儲存庫執行；現有可下載安裝套件仍為 v1.1.1，不包含這些更新。真實任務是否成功仍以工具回執和平台結果為準。

```powershell
git clone --depth 1 https://github.com/Akatosh6DW/Amadeus.git
cd Amadeus
.\start.cmd
```

第一次執行會自動安裝桌面和傳出的語音環境，並下載約 614 MB 的已發布 voice/context 資源、GPT-SoVITS/Python/PyTorch 等數 GB 依賴；首次仍需你在「設定 → API」填入自己的 API Key。接收 QQ 語音的本機 ASR 是可選能力，原始碼語音環境包含 faster-whisper，但 `start.cmd` 不會下載 QQ 識別所用的 small 模型，需要另行準備本機模型，見 [QQ 設定與使用說明](integrations/qq/README.md#接收-qq-语音本地-asr)。下載中斷或失敗時保留專案內快取，重新執行同一個 `start.cmd` 即可繼續。

孫吧/抗吧語料屬於可選本機資料，不隨公開原始碼或 Release 分發；QQ 設定、人格選擇、接收的語音和本機語料邊界見 [QQ 設定與使用說明](integrations/qq/README.md)。

## 環境要求

### QQ 快速設定

QQ 功能預設關閉。原始碼首次安裝會下載固定版本的 NapCat 接入元件；發布構建會內建同一個元件。**不包含也不下載 QQ 客戶端**，請先自行安裝 QQ NT。

1. 開啟 **設定 → QQ → 帳號與登入**，點選 **連線本機 QQ**。已有普通 QQ 正在執行時先自行退出；找不到客戶端時展開「手動指定 QQ 路徑」。
2. 用手機 QQ 掃描 QR Code，核對頁面顯示的登入帳號；按頁面提示點選 **改用已登入帳號** 或 **連線這個帳號**。登入成功不會自動開始回覆。
3. 在 **主人權限** 填寫你本人的 QQ 號；這是遠端控制者，與助手登入的帳號分開。
4. 在 **回覆誰 → 新增好友或群** 選擇對象並「加入清單」。點每個對象旁的 **設定**，進入獨立頁面設定身分、人格、群觸發方式、文字或語音和間隔。
5. 在 **回覆設定** 選擇「自動回覆，直接傳送」或「先產生草稿，我確認後才傳送」，點選 **儲存設定**，再點選頂部 **▶** 開始。**⏸** 暫停回覆；「退出 QQ 背景」停止連線。

地址、金鑰和對象設定自動儲存在本機。**帳號與登入** 可新增帳號或切換已儲存設定；切換設定後保持暫停，還需登入相同 QQ 號。每個帳號的聯絡人、回覆要求和聊天上下文獨立，不會因為填寫新號碼就完成 QQ 登入。

已在這臺電腦登入過的帳號可使用 NapCat 的自動登入目標複用本機憑據，詳見 [記住帳號與自動登入](integrations/qq/README.md#记住账号与自动登录)。這屬於本機設定；顯式重新登入/換號會清空目標，憑據失效時仍可能需要掃描 QR Code。

完整步驟、按鈕說明、主人遠端控制、新帳號驗收和疑難排解見 [QQ 設定與使用說明](integrations/qq/README.md)。NapCat 官方壓縮包約 34.2 MiB，展開約 109.3 MiB；複用 Amadeus 執行環境，不需要安裝 AstrBot。v1.1.1 安裝套件已內建 QQ 接入元件，首次使用仍需你選擇帳號並掃描 QR Code登入。

### 執行條件

- Windows 10/11 x64，建議 16 GB 記憶體。
- Release 安裝約需 30 GB 空間，原始碼執行約需 40 GB。
- 有 NVIDIA 顯示卡時語音合成更快，沒有也可以用 CPU 執行。

## 資料和隱私

聊天、個人記憶、工程偏好、待辦和設定儲存在本機；QQ 設定不會作為個人事實寫進長期記憶。對話、識圖、自動摘要和表情判斷等功能會將所需內容傳送到你設定的模型服務；聯網工具會存取相應網站。

## 使用自主生活

自主生活預設關閉。想讓她偶爾透過 QQ 來找你閒聊：先在 QQ 頁儲存代理帳號和主人 QQ，再在自主生活中勾選「允許主動 QQ 聊天」、選擇主人並儲存。只有一位主人時會自動選取。聊天有獨立的考慮時間，不會因為一直閱讀而被擠掉；是否開口、聊什麼和說多少仍由她決定，沒有固定開場。桌面對話、生活經歷、空間動態和你與她的 QQ 主人私訊可進入同一段日常上下文；訊息按意思分成完整的小段。QQ 自動傳送/待審核/暫停設定繼續生效，聊天紀錄會顯示真實傳送狀態。要持續執行，還需開啟自主生活並保持後端和 QQ 在線。

QQ 空間與自主生活共享興趣、近期經歷和實際發布回執：生活中的發現可以成為動態，獨立空間瀏覽讀到的內容也可以成為下一次閒聊的話題。原有空間自動瀏覽設定繼續有效；訊息和動態不會僅憑模型說「完成」就記作已經傳送。

自主生活將 QQ 閱讀分享固定為文字，方便閱讀和引用；普通聊天的語音設定保持不變。已傳送語音若存在同對話的文字底稿與平台回執，可在後續引用中恢復原文；這不會改寫 QQ 中原有的語音氣泡。定時任務也會保留有效正文，可選語音失敗時仍可文字交付，真實執行失敗與未知傳送繼續單獨報告。

桌面對話和你與她的 QQ 私訊也會進入同一段日常生活；QQ 以所選帳號與主人身分匹配，其他聯絡人、群組聊天不計入。她可以留下持續興趣與沒聊完的話題，結合後續交流決定繼續或放下；「還惦記的事」中可以暫停、繼續、結束。重新啟動保留記錄，時間到了只會重新考慮，不強制開口。

人格與通用表達設定在桌面、自主生活和主人的預設 QQ 人格之間共用。她自己的活動和主動話題以論文、科學、網際網路、網路文化與亞文化等能夠實際接觸的內容為主，區分讀到、想到和親身做過，不虛構線下生活經歷。你談現實生活時，她仍可自然接話。

從原始碼執行時開啟 **設定 → 自主生活**，填寫興趣、非敏感閱讀目錄和起始網頁或 RSS/Atom 網址，然後儲存。可以先點「試執行一次」，檢視實際閱讀記錄、興趣筆記和動態草稿；開啟後，程式會在活動時段自動執行，關閉設定頁不影響背景。

起始來源旁的「新增常用來源」可加入 Bluesky、Bangumi、arXiv 天文訂閱和 Python 更新；也可自行填寫公開地址。新增來源會保留已有輸入，點選「儲存設定」後生效。公開閱讀沿用「權限 → 網路搜尋」與自主生活的「允許讀取公開來源」，不需要登入這些平台，也不會替你開啟權限；這些平台在本次更新中仍只讀，不支援登入、關注、評論或發文。

普通聊天也可以請她搜尋 Bluesky 貼文、檢視某個公開帳號或貼文討論、查 Bangumi 作品、尋找 arXiv 論文或閱讀訂閱。Bluesky 回傳貼文文字，Bangumi 回傳條目介紹與後設資料，arXiv 回傳題目、作者、摘要和原文連結，RSS/Atom 回傳訂閱實際提供的內容；讀過摘要不等於讀過論文全文，條目介紹也不等於觀看作品。

頻率只需調「總體活躍程度」。標準 100% 時，閱讀探索約每 2 小時、考慮找你聊天約每 3 小時、整理想法約每 6 小時、考慮空間分享約每 12 小時；200% 將這些間隔減半，50% 將間隔加倍。四項分別計時並儲存，下次時間在頁面中可見，重新啟動不會清空。剛開啟時會錯開安排：閱讀先開始，聊天約 15 分鐘後首次考慮，整理約 1 小時後，空間約 2 小時後（同樣隨總體活躍程度縮放）。這些是考慮機會，不是固定發言任務；沒有想說的可以安靜結束。發過主動私訊後，至少再等一個聊天間隔；活動時段、原有帳號權限、審核方式、每日空間發布上限繼續生效。

舊版所有活動共用的每日次數不再擠佔聊天機會；舊設定檔案仍可讀取。手動試執行不推遲四項自動安排，實際產生的聊天和發布仍計入原有傳送保護。每次活動繼續使用有界的工具步數和時間，多個到期活動依次執行，停機期間的次數不會成批補發。

閱讀目錄必須由你明確選擇，當前支援其中的 UTF-8 文字；被讀取的內容會傳送到所選模型，請不要放入密碼、私信或其他敏感材料。公開網頁地址只是探索起點，她可以繼續存取其他公開來源。檔案和網頁仍受全域讀取權限約束。日記和興趣筆記儲存在本機獨立資料庫，不自動寫入你的個人事實記憶；在桌面對話中可讓她檢視生活日記，聊聊最近讀了什麼。

發布預設只存草稿，可編輯後傳送或丟棄。要自動發 QQ 空間動態，可點選「使用當前代理帳號」，或將帳號留空，在儲存/試執行時綁定 QQ 頁當前設定的代理帳號；也可手動填寫完整 QQ 號。綁定會儲存，之後切換代理帳號不會自動更換生活帳號或已有草稿的帳號。選擇可見範圍與每日額度，再啟用「自動發布」；現有 QQ 連線、帳號範圍和空間發布權限仍須有效。這裡的空間草稿設定獨立於 QQ 私訊/群組聊天的審核模式。保留現有 QQ 空間發布介面卡，尚未接入其他平台的登入瀏覽器發文。

「立即停止」會關閉後續喚醒並取消尚未執行的操作；已發出的網路請求無法撤回。結果未知的發布會保留回執供核對，不會自動重發。此功能依據結構化工具呼叫執行，不靠關鍵字或正則猜測使用者授權。首次真實帳號發布前，建議先用「僅產生草稿」核對內容和範圍。

表情系列可在「設定 → 表情」控制前端回覆，在「QQ → 對象旁的設定 → 表情包系列與比例」單獨控制好友或群。勾選系列後拖動滑塊，例如咒術回戰 40%、奶蛙 20%，其餘約 40% 不主動配圖。總和不超過 100%；比例決定嘗試配圖的頻率，模型仍會跳過不貼切的圖，明確索要圖片則優先完成請求。QQ 對話關閉自訂後繼承 QQ 預設設定；自訂但不選系清單示不主動配圖。

## 已知問題

設定儲存、待辦建立和 QQ 實際傳送是不同的結果。QQ 自動傳送成功預設不額外刷成功氣泡；失敗或傳送狀態未知時會說明，詳細結果可檢視 QQ 動態。提醒需要後端保持執行；程式退出、電腦休眠或 QQ 離線時不能保證按時送達。

當前版本已移除按使用者措辭猜授權、重複登記任務等誤攔路徑；使用者設定的權限、帳號/收件人範圍、暫停/審核模式及防重複傳送仍有效。完整缺陷與實際驗收範圍由本機 `BUGS.md` 維護，不能把一次測試透過理解為所有外部平台永不失敗。
